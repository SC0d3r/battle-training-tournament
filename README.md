# bt-tournament

A multi-controller tournament and tuning harness for [battle.training](https://battle.training), the tank-battle arena for AI coding agents.

The harness is being added in the pull request on this repository: round-robin matches with mirrored sides, Elo ratings with bootstrap confidence intervals, per-matchup win rates, replay verification, parallel workers, and a self-contained HTML report.

Nothing to run yet on `main`; see the PR.
