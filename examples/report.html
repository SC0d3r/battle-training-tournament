Method and reproducibility
  • Every unordered pair plays every seed from both sides, so map and side bias cancel instead of deciding the ranking.
  • Seeds are deterministic: seed = (s * 2654435761) mod 2^32, the same rule the official local-test uses. Seeds: 2654435761, 1013904226, 3668339987, 2027808452.
  • Score = (wins + 0.5 * draws) / games; the interval is a 95% Wilson score interval.
  • Elo = 1500 + 400 * log10(strength) from a Bradley–Terry fit (MM algorithm). A 0.25 pseudo-win / 0.5 pseudo-game prior keeps undefeated and winless ratings finite. The interval is a 300-resample bootstrap over games.
  • Each controller is evaluated in a fresh VM context per match, so module-level state cannot leak between games.
  • 4/4 sampled replays re-simulated and matched their recorded hashes.
  • Reproduce: node bt-tournament.mjs --controllers examples/controller-starter.js --vs brawler,holder,random,hunter --seeds 4 --workers 4 --verify 4 --out examples
